Guess Market server

The server is running. Start the Guess Market client to use it; the client finds this server by itself.

Every request below except /login needs a logged-in session, and every answer is JSON.

POST /login?username=log in by name
POST /logoutlog out
GET /userseverybody, with balance and whether they run an event
GET /accountyour own details
GET /account/ledger?after=the lines of your account after the ones you have
POST /account/deposit?amount=load funds
GET /eventsevery event
POST /events/uploadan events file, as a multipart part named file
GET /events/lmsr?event=one LMSR event
GET /events/book?event=one order book event
POST /events/open?event=open an event you run
POST /events/close?event=&winner=close an event you run
POST /trade/buy?event=&option=&quantity=buy from an LMSR event
POST /trade/sell?event=&option=&quantity=sell back to an LMSR event
POST /trade/order?event=&option=&side=&quantity=&price=place an order in a book
GET /chat?after=the chat messages after the ones you have
POST /chat?message=say something in the chat
